For my “Teletraffic Models and Measurements” project, I independently developed an SDN-based solution that simulates and analyzes telecommunication traffic in a controlled network environment. This project harnesses both Python and Bash scripting to create a flexible, emulated topology and automate its configuration.

Using Python with Mininet, I built a custom network topology that incorporates multiple hosts and Open vSwitch (OVS) switches. I developed a tailored SDN controller application which configures VLAN settings—assigning specific tags to hosts and establishing trunk links between switches—to effectively segment and manage traffic flows. The SDN component not only provided a platform to experiment with remote control functions (with integration considerations for controllers like ONOS) but also enabled dynamic network reconfiguration and real-time traffic management.

Complementing this, I crafted Bash scripts to automate the setup and teardown of the network environment. These scripts manage network namespaces, create virtual ethernet (veth) pairs, instantiate OVS bridges, and set up trunk links—ensuring that the network is consistently configured for testing. By combining these scripting techniques, I performed connectivity tests, simulated realistic traffic segregation, and obtained meaningful metrology data for performance evaluation.

Overall, the project served as a comprehensive exercise in teletraffic modeling, SDN implementation, and network metrology. It deepened my understanding of modern network virtualization, offered hands-on experience with both shared and distributed network configuration tools, and showcased the potential of SDN for automated traffic management.
